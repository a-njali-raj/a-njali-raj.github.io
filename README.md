# Anjali Raj — Portfolio

A clean, responsive, light-theme developer portfolio built with React and Vite.

## Run locally

Make sure Node.js is installed, then:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Build for production

```bash
npm run build
```

## Customize

Most portfolio content is in:

```text
src/App.jsx
```

Styling is in:

```text
src/styles.css
```

Update your links, project descriptions, skills, education and any other details before publishing.

## Deploy

This project can be deployed to a static hosting service such as Vercel, Netlify or GitHub Pages.

Before deployment, run:

```bash
npm run build
```
